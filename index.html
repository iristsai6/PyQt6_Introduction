PyQt6 完整元件分類資料庫

點擊下方分類分頁或左側具體元件按鈕，右側將即時連動顯示互動預覽與程式碼 (Code)

頂層視窗與對話框 (Top-level Windows & Dialogs)

類別名稱 (CLASS) 說明與常見用途
標準主視窗，內建選單列、工具列、狀態列與中央核心區域。
基礎視窗元件，所有 UI 元素的基底類別，也可作為獨立視窗。
標準對話框視窗，常用於設定、確認或子表單流程。
系統訊息提示框（警告、確認、錯誤彈窗）。[cite: 8]
檔案與資料夾選取對話框（開啟/儲存檔案）。[cite: 8]

版面配置管理器 (Layout Managers)

類別名稱 (CLASS) 說明與常見用途
垂直線性佈局（由上而下依序排列）。
水平線性佈局（由左而右依序排列）。
二維網格佈局（以列、欄座標精確定位）。

按鈕類元件 (Buttons)

類別名稱 (CLASS) 說明與常見用途
標準命令按鈕，支援文字與圖示。
工具列按鈕（通常搭配圖示與選單使用）。
核取方塊（可獨立勾選多個選項或半選狀態）。

輸入與數值調整元件 (Input Widgets)

類別名稱 (CLASS) 說明與常見用途
單行文字輸入框（支援密碼遮罩、提示字串）。
滑動條（用於音量、進度等連續數值調整）。

顯示類元件 (Display Widgets)

類別名稱 (CLASS) 說明與常見用途
標籤元件（顯示純文字、富文本 HTML、圖片或 GIF 動畫）。
進度條（百分比或動態讀取條）。

容器與版面群組元件 (Containers)

類別名稱 (CLASS) 說明與常見用途
帶有邊框與標題的群組區塊。
分頁標籤容器。

資料檢視與清單元件 (Item Views & Lists)

類別名稱 (CLASS) 說明與常見用途
試算表風格的行列表格檢視。
階層式樹狀檢視（適合檔案總管、目錄樹）。
右側即時互動與 CODE：QMainWindow

from PyQt6.QtWidgets import QApplication, QMainWindow
import sys

app = QApplication(sys.argv)
